#### [2.0.0](https://github.com/context-dot-dev/n8n-integration/compare/1.3.0...2.0.0)

> 5 June 2026

##### Breaking Changes

- **Package rename**: `n8n-nodes-branddev` → `n8n-nodes-context-dev`. Uninstall the old package and install the new one.
- **Node rename**: internal name changed from `branddev` to `contextDev`. Existing workflows must be recreated.
- **Credential rename**: `branddevApi` → `contextdevApi`. Re-enter your API key under the new credential type.
- **Base URL**: all requests now target `https://api.context.dev/v1` (was `api.brand.dev/v1`).
- **Resource change**: `Screenshot & Styleguide` resource removed — Screenshot, Extract Styleguide, and Extract Fonts are now under `Web Scraping`.
- **Parameter rename**: `speed_optimized` → `maxSpeed` to match current API.

##### Bug Fixes

- Fixed NAICS endpoint: `GET /brand/naics` → `GET /web/naics` (every NAICS lookup was returning 404)
- Fixed SIC endpoint: `GET /brand/sic` → `GET /web/sic`
- Fixed Screenshot/Styleguide/Fonts endpoints: `/brand/*` → `/web/*`
- Fixed Scrape to Markdown: was incorrectly using `POST`; correct method is `GET`
- Fixed Scrape HTML and Scrape Images: same incorrect `POST` → `GET` fix
- Fixed Crawl Website URL: `POST /web/crawl/md` → `POST /web/crawl`
- Fixed Crawl Sitemap URL: `GET /web/sitemap` → `GET /web/scrape/sitemap`

##### New Resources

- **Web Scraping** — 11 operations: Crawl Sitemap, Crawl Website, Extract Competitors, Extract Fonts, Extract Structured Data, Extract Styleguide, Scrape HTML, Scrape Images, Scrape to Markdown, Screenshot, Search
- **Utility** — 2 operations: Prefetch by Domain, Prefetch by Email

##### New Operations

- **Industry Classification**: added `Classify SIC` (`GET /web/sic`)
- **AI Data Extraction**: added `AI Query` (`POST /brand/ai/query`) and `Extract Single Product` (`POST /brand/ai/product`)
